# MONARK specifications

This repository holds the public specifications of MONARK.

- [`KATA-SPEC.md`](KATA-SPEC.md): the kata method. It defines how a kata value is computed, with its conformance vectors in `vectors.json`.
- [`contract-1.1.0/CONTRACT.md`](contract-1.1.0/CONTRACT.md): the gate contract, version 1.1.0. It defines the formats the gate speaks, its errors and its policy table files, with its schemas, table files and conformance vectors in the same directory.

Each version of the gate contract is published under its own directory. A published file is never withdrawn.
